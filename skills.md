# Skills

This file catalogs the reusable skills and slash commands available in this project.

## Available Skills

| Skill | When to use |
|---|---|
| `/netlify-deploy` | Deploy to Netlify and configure `start.empowrcic.org` |
| `/pre-deploy-security` | Run before any deploy — FAILs block the deploy |
| `/webapp-testing` | Test UI at 480px with Playwright — use after any change |
